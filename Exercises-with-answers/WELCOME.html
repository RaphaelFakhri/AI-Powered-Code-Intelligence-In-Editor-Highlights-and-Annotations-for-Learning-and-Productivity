🔨 The Tool

You have access to a code intelligence tool built into this editor. The goal of this study is to explore whether it helps you feel more productive, understand code better, and stay focused compared to traditional coding or commercial AI tools you may have used.

✍️ Selection + Overview

Select any code, then click "Get Started". The tool generates an overview of your selection. From there:

Embed Inline — adds the overview as a code comment
API — function signatures & parameters
Concept — explains what the function does
Usage — how it's typically used

🎤 Voice Mode

Toggle the voice button on, then speak naturally:

"Select lines 7 to 11"Select a range
"Select function calc"Select a function
"Give me an overview"Get an AI overview
"API" / "Concept"Get specific details
Any questionAsk anything freely

👁️ Gaze Mode

Toggle gaze mode on, then simply look at the code. Look at a function long enough and it will be automatically selected. Look at the "Get Started" button to trigger an overview. A natural, hands-free way to explore and understand code.
